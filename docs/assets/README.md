# Оформление README

- `cover.svg` — обложка с названием проекта, гербом Астаны и картой районов.
- `rules.svg` — краткие правила симулятора.

SVG содержат только векторную графику и текст: без JavaScript, внешних шрифтов и HTML `foreignObject`.
Обложка целиком ведёт на живое демо через ссылку в корневом README.

Цвета повторяют интерфейс: фон `stone-50`, белые панели, границы `stone-200`, текст `stone-900`
и бирюзовый акцент `teal-700`. Геометрия и цвета герба взяты из
[`frontend/public/astana-emblem.svg`](../../frontend/public/astana-emblem.svg);
CSS-классы заменены эквивалентными SVG-атрибутами для автономного отображения.
[Источник и лицензия герба](../../frontend/public/astana-emblem.LICENSE.txt).

Геометрия обложки взята из `frontend/src/data/districts.json` и спроецирована в Меркатор.
Это изображение районов учебного кейса, а не новая версия административных границ.
Данные © OpenStreetMap contributors, лицензия ODbL. Преобразования и источники: [MAP_DATA.md](../MAP_DATA.md).

Видео хранится во вложениях GitHub, чтобы не увеличивать Git-репозиторий медиафайлами.
При замене загрузите новый MP4 как вложение к PR и перенесите полученный URL отдельным абзацем в README.
Проверяйте встроенный плеер на странице репозитория после изменения.
